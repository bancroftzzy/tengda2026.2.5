# 界面操作指南

## 📋 施工信息录入界面说明

### 界面布局

界面分为三个区域:

1. **输入区域**（上方）- 输入单个工况的参数
2. **列表区域**（中间）- 显示所有已添加的工况
3. **操作按钮**（右侧）- 执行各种操作

### 输入参数说明

#### 第一行参数

| 参数名 | 说明 | 示例 | 备注 |
|--------|------|------|------|
| 开挖深度(m) | 本工况开挖深度 | 3.0 | 正值表示向下开挖 |
| 激活支撑 | 是否安装支撑 | 是/否 | 下拉选择 |

#### 第二行参数（拆换撑相关）

| 参数名 | 说明 | 示例 | 备注 |
|--------|------|------|------|
| 拆除支撑 | 是否拆除支撑 | 是/否 | 下拉选择 |
| 支撑编号 | 拆除第几道支撑 | 0 | 从0开始,-1表示不拆除 |
| 浇筑顶板 | 是否浇筑顶板 | 是/否 | 下拉选择 |
| 顶板标高(m) | 顶板所在标高 | -3.0 | 负值表示地面以下 |

#### 第三行参数（回筑相关）

| 参数名 | 说明 | 示例 | 备注 |
|--------|------|------|------|
| 顶板厚度(m) | 顶板厚度 | 0.2 | 通常0.15-0.3m |
| 回筑深度(m) | 回筑深度 | -3.0 | 负值表示向上回填 |

### 列表显示说明

列表显示所有已添加的工况,包含以下列:

| 列名 | 说明 |
|------|------|
| 编号 | 工况序号 |
| 开挖深度 | 开挖深度(m) |
| 激活支撑 | 是否安装支撑 |
| 拆除支撑 | 是否拆除支撑 |
| 支撑编号 | 拆除支撑的编号 |
| 浇筑顶板 | 是否浇筑顶板 |
| 顶板标高 | 顶板标高(m) |
| 顶板厚度 | 顶板厚度(m) |
| 回筑深度 | 回筑深度(m) |

### 操作按钮说明

| 按钮 | 功能 | 说明 |
|------|------|------|
| 清空 | 清空所有工况 | 删除列表中的所有工况 |
| 删除 | 删除选中工况 | 删除列表中选中的工况 |
| 写入 | 保存到文件 | 将工况数据保存为文本文件 |
| 读取 | 从文件读取 | 从文本文件读取工况数据 |
| 插入 | 插入工况 | 在选中位置插入新工况 |
| 追加 | 追加工况 | 在列表末尾添加新工况 |

## 🎯 操作步骤

### 添加工况

1. 在输入区域填写参数
2. 点击"追加"按钮
3. 工况会显示在列表中

### 修改工况

1. 在列表中选中要修改的工况
2. 点击"删除"按钮删除该工况
3. 重新填写参数并点击"插入"或"追加"

### 保存工况

1. 点击"写入"按钮
2. 选择保存位置和文件名
3. 文件会保存为制表符分隔的文本文件

### 读取工况

1. 点击"读取"按钮
2. 选择要读取的文件
3. 工况数据会显示在列表中

## ⚠️ 注意事项

### 参数输入

1. **数值参数**: 必须输入数字,不能为空
2. **下拉选择**: 必须选择"是"或"否",不能为空
3. **支撑编号**: 
   - 从0开始计数
   - 不拆除时输入-1
   - 必须是整数

### 工况顺序

1. **先浇筑顶板,再拆除支撑**
2. **拆除支撑后,再回筑**
3. **回筑深度为负值**（-3.0表示向上回填3m）

### 参数合理性

1. **开挖深度**: 通常3-5m
2. **顶板厚度**: 通常0.15-0.3m
3. **回筑深度**: 建议每次3-5m
4. **顶板标高**: 必须在围护结构范围内

## 🔍 常见问题

### Q1: 如何修改已添加的工况?

A: 选中该工况,点击"删除",然后重新添加。

### Q2: 如何在中间插入工况?

A: 选中插入位置的工况,填写参数后点击"插入"。

### Q3: 保存的文件格式是什么?

A: 制表符分隔的文本文件(.txt),可以用Excel或记事本打开。

### Q4: 读取文件时提示格式错误?

A: 检查文件是否为制表符分隔,表头是否正确。

### Q5: 如何快速创建多个相似工况?

A: 
1. 添加第一个工况
2. 点击"写入"保存
3. 用Excel打开文件
4. 复制并修改行
5. 保存后点击"读取"

## 💡 使用技巧

### 技巧1: 使用Excel编辑

1. 点击"写入"保存为文本文件
2. 用Excel打开文件
3. 批量编辑工况数据
4. 保存为制表符分隔的文本文件
5. 点击"读取"重新导入

### 技巧2: 创建模板文件

1. 创建常用的工况组合
2. 保存为模板文件
3. 每次使用时读取模板
4. 根据实际情况修改

### 技巧3: 分步添加

1. 先添加开挖和支撑工况
2. 测试计算是否正常
3. 再添加拆换撑和回筑工况
