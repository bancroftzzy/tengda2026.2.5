## 1 程序简介
&emsp;&emsp;本围护侧向变形的主动控制计算程序以腾达建设集团股份有限公司编撰的《软土条形深基坑变形的施工控制理论与实践研究》中提出的主动控制方法为理论基础，以浦东南路站A-2坑为工程背景，建立荷载结构模型进行基坑围护结构侧向变形计算及控制。




## 2 试运行环境
- 操作系统：*Windows11 家庭中文版*，版本号21H2
- 处理器：*Intel i7-12700H*，基准频率2.30GHz
- Visual Studio版本：*VS2022 企业版*
- .NET框架：*.NET Framework 4.8*
