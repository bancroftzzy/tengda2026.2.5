# 拆换撑与基坑回筑功能使用说明

## 📋 功能概述

本次更新为程序添加了以下新功能：
1. **拆除支撑**：模拟施工过程中拆除临时支撑
2. **浇筑顶板**：模拟地下室顶板浇筑
3. **基坑回筑**：模拟基坑回填过程

## 🔧 实现方法

采用**增量计算法**（基于杨光华的理论）：
- 拆除支撑时施加反向荷载，保证位移连续性
- 回筑时施加土压力增量，考虑回填土特性
- 逐步累加各施工步的位移增量

## 📝 输入文件格式

### 方法1: 通过界面输入（推荐）

程序提供了图形界面用于输入工况数据:

1. 打开主程序,点击"施工信息录入"按钮
2. 在弹出的窗口中填写各项参数:
   - **开挖深度(m)**: 本工况开挖深度,正值表示向下开挖
   - **激活支撑**: 是否在本工况安装支撑
   - **拆除支撑**: 是否在本工况拆除支撑
   - **支撑编号**: 拆除第几道支撑(从0开始),-1表示不拆除
   - **浇筑顶板**: 是否在本工况浇筑顶板
   - **顶板标高(m)**: 顶板所在标高
   - **顶板厚度(m)**: 顶板厚度
   - **回筑深度(m)**: 回筑深度,负值表示向上回填
3. 点击"追加"按钮添加工况
4. 点击"写入"按钮保存到文件

### 方法2: 手动编辑文本文件

扩展的 `3-LoadCasesInfo.txt` 格式:

```
编号	开挖深度	是否加支撑	是否拆支撑	拆除支撑编号	是否浇筑顶板	顶板标高	顶板厚度	回筑深度
```

### 参数说明

| 列号 | 参数名 | 类型 | 说明 | 示例 |
|-----|--------|------|------|------|
| 1 | 编号 | 整数 | 工况编号 | 1 |
| 2 | 开挖深度 | 浮点数 | 本工况开挖深度（m），正值表示向下开挖 | 3.0 |
| 3 | 是否加支撑 | 布尔值 | True/False | True |
| 4 | 是否拆支撑 | 布尔值 | True/False | False |
| 5 | 拆除支撑编号 | 整数 | 拆除第几道支撑（从0开始），-1表示不拆除 | 0 |
| 6 | 是否浇筑顶板 | 布尔值 | True/False | False |
| 7 | 顶板标高 | 浮点数 | 顶板所在标高（m） | -3.0 |
| 8 | 顶板厚度 | 浮点数 | 顶板厚度（m） | 0.2 |
| 9 | 回筑深度 | 浮点数 | 回筑深度（m），负值表示向上回填 | -3.0 |

### 向后兼容性

- 如果只有前3列，程序会自动使用默认值（与旧版本兼容）
- 可以逐步添加列，程序会自动识别

## ⚙️ 关键参数说明

### 1. 拆除支撑编号

- **编号从0开始**：第1道支撑编号为0，第2道为1，以此类推
- **拆除顺序**：通常从上到下拆除（先拆上面的支撑）
- **注意**：拆除前必须确保该支撑已经安装（IsActiveSupport = True）

### 2. 顶板标高

- **标高值**：相对于开挖地面的标高（负值表示地面以下）
- **位置要求**：顶板标高必须在围护结构范围内
- **节点匹配**：程序会自动查找对应标高的节点

### 3. 回筑深度

- **负值表示向上回填**：例如 -3.0 表示向上回填3米
- **分层回填**：建议每次回填3-5米
- **压实系数**：程序默认回填土压实系数为0.8

## 🔍 计算原理

### 拆除支撑的增量法

```
步骤1：记录支撑抗力 F
步骤2：钝化支撑单元（isAlive = false）
步骤3：在围护墙上施加反向荷载 -F
步骤4：重新求解

结果：围护墙位移连续，不会突变
```

### 回筑的增量法

```
步骤1：更新开挖面标高（向上）
步骤2：激活被回填区域的土弹簧
步骤3：调整土弹簧刚度（考虑压实系数）
步骤4：施加回填土压力增量
步骤5：重新求解

结果：围护墙受力减小，位移减小
```

## 📊 输出结果

程序会在输出窗口显示：
- 拆除支撑的信息（支撑编号、抗力、反向荷载）
- 浇筑顶板的信息（标高、厚度）
- 回筑的信息（回筑深度、当前开挖面标高）

## ⚠️ 注意事项

1. **工况顺序**：
   - 先浇筑顶板，再拆除支撑
   - 拆除支撑后，再回筑

2. **数值稳定性**：
   - 回筑不宜过快，建议分层进行
   - 拆撑前确保顶板已浇筑

3. **参数合理性**：
   - 顶板厚度通常为0.15-0.3m
   - 回筑深度建议每次3-5m
   - 压实系数可在代码中调整（默认0.8）

## 🐛 常见问题

### Q1：拆撑后位移突然增大？
A：检查是否在拆撑前浇筑了顶板。如果没有顶板，拆撑后围护墙失去约束，位移会增大。

### Q2：回筑后位移没有减小？
A：检查回筑深度是否为负值（-3.0表示向上回填3m）。

### Q3：顶板浇筑失败？
A：检查顶板标高是否在围护结构范围内，程序会自动查找对应标高的节点。

### Q4：支撑编号错误？
A：支撑编号从0开始，第1道支撑编号为0。检查RemoveSupportIndex列的值。
