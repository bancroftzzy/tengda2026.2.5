# 土弹簧模型详解

## 📋 概述

程序使用的是**m法土弹簧模型**（也称为"比例系数法"或"弹性地基梁法"），这是基坑工程中最常用的土体-结构相互作用模型之一。

## 🎯 土弹簧的本质

### 物理意义

土弹簧模拟的是**土体对围护墙的水平约束作用**：

```
围护墙外侧                围护墙
    土体  ←→ [弹簧] ←→  墙体
    
当墙体向土体侧移动时:
- 土体产生反力
- 反力大小 = 刚度 × 位移
- 类似于弹簧的胡克定律
```

### 为什么叫"弹簧"?

因为土体的反力与位移成正比（在小变形范围内）：
```
F = k × δ
```
这与弹簧的力学特性完全一致！

## 🔧 m法模型

### 基本假定

**m法**假定土的水平抗力系数随深度线性增加：

```
k(z) = m × z

其中:
- k(z): 深度z处的水平抗力系数 (kN/m³)
- m: 水平抗力比例系数 (kN/m⁴)
- z: 距离地面的深度 (m)
```

### 物理意义

- **浅层土**: 约束较弱 (k小)
- **深层土**: 约束较强 (k大)
- **线性增长**: 简化假定,工程上足够准确

### 与其他方法的对比

| 方法 | 假定 | 适用范围 |
|------|------|----------|
| **m法** | k = m × z | 一般土层,最常用 |
| k法 | k = 常数 | 坚硬土层 |
| c法 | k = c / z | 软弱土层 |

程序使用的是**m法**,适用于大多数工程情况。

## 📐 土弹簧的构造

### 几何布置

```
围护墙节点分布:
    0m  ●────────────────────● (地面)
        │                    │
   -1m  ●────────────────────●
        │                    │
   -2m  ●────────────────────●
        │                    │
   -3m  ●────────────────────●
        
每个节点处的土弹簧:
    外侧节点 ←→ 墙上节点
    (Nx=-1)     (Nx=0)
```

### 单元类型

土弹簧使用**连杆单元 (Link Element)**:
- 只承受轴向力
- 不承受弯矩和剪力
- 刚度矩阵简单

### 节点连接

```
Left节点:  (Nx = -1, Ny = 某高度)  ← 围护墙外侧
Right节点: (Nx = 0,  Ny = 某高度)  ← 围护墙上

水平距离: 1m (形式上的距离)
实际作用: 提供水平约束
```

## 🧮 刚度计算

### 计算公式

程序中土弹簧的刚度计算公式:

```csharp
ks = a × b × m × z

其中:
- a: 单元长度 (上下节点间距, m)
- b: 水平宽度 (取1.0m, 单位宽度)
- m: 水平抗力比例系数 (kN/m⁴)
- z: 土层到地面的距离 (m)
```

### 详细推导

#### 1. 土的水平抗力系数

根据m法:
```
k(z) = m × z  (kN/m³)
```

#### 2. 单位面积的刚度

对于单位面积 (1m × 1m):
```
k_area = k(z) × 1m = m × z  (kN/m²)
```

#### 3. 单元的总刚度

对于高度为a、宽度为b的单元:
```
K_spring = k_area × a × b = m × z × a × b  (kN/m)
```

#### 4. 程序中的实现

```csharp
// 初始化时
ks = (mf.Nodes[i-1].Ny - mf.Nodes[i].Ny) × 1.0 × j.M × 1e6 × (mf.ElevOfGround - mf.Nodes[i].Ny)
     └─────────────┬─────────────┘   └┬┘  └─┬─┘        └──────────┬──────────┘
              单元长度 a              宽度b   m×1e6              深度 z
                                              (单位转换)
```

**注意**: `j.M × 1e6` 是因为m的单位是 MN/m⁴,需要转换为 kN/m⁴

### 开挖后的刚度更新

开挖后,土弹簧的刚度需要更新,因为"地面"下降了:

```csharp
// 开挖后
ks = elemLength × 1.0 × j.M × 1e6 × (Loadcase.CurElev - mf.Elements[index].Left.Ny)
                                      └──────────┬──────────┘
                                          新的深度 z
                                    (从当前开挖面算起)
```

## 🎨 土压力的施加

### 两步法

程序使用**两步法**施加土压力:

#### 步骤1: 施加土压力荷载

在围护墙上直接施加土压力:
```csharp
// 主动土压力系数
Ka = tan²(45° - φ/2)

// 土压力
σ = Ka × γ × z - 2c × √Ka

// 转换为节点荷载
Fy_i = -(7qi + 3qj) / 20 × L
Fy_j = -(3qi + 7qj) / 20 × L
Mom_i = (3qi + 2qj) / 60 × L²
Mom_j = -(2qi + 3qj) / 60 × L²
```

#### 步骤2: 通过土弹簧初应变平衡

```csharp
// 1. 土弹簧刚度放大1e20倍 (近似刚性)
ks_temp = ks × 1e20

// 2. 求解,得到土弹簧反力
FEM.Solve(...) → RForce

// 3. 计算初应变
IniStrn = RForce / (E × A)

// 4. 恢复土弹簧刚度
ks = ks / 1e20
```

### 为什么这样做?

这样做的目的是让土弹簧**自动平衡土压力**:

```
初始状态:
土压力 → 围护墙 → 土弹簧反力

通过初应变:
土弹簧主动产生反力 = 土压力
围护墙初始位移 ≈ 0
```

## 🔄 施工过程中的变化

### 1. 初始状态

```
地面 (0m)
├─ 土弹簧: 全部激活
│  刚度: ks = a × b × m × z
│  初应变: 平衡初始土压力
└─ 围护墙: 受土压力作用
```

### 2. 开挖至-3m

```
原地面 (0m)
├─ 土弹簧: 钝化 (isAlive = false)
│
新地面 (-3m)
├─ 土弹簧: 激活,刚度更新
│  新刚度: ks = a × b × m × (z - 3)
│  (深度从新地面算起)
└─ 围护墙: 受更新后的土压力
```

### 3. 回筑至-3m

```
原地面 (0m)
├─ 土弹簧: 重新激活
│  刚度: ks = a × b × m × z × 0.8
│  (考虑压实系数0.8)
│  初应变: 施加回填土压力
│
当前地面 (-3m)
└─ 土弹簧: 继续激活
```

## 🎯 土弹簧的作用

### 1. 约束围护墙

```
无土弹簧:
土压力 → 围护墙 → 无约束 → 位移很大 ❌

有土弹簧:
土压力 → 围护墙 ← 土弹簧反力 → 位移合理 ✅
```

### 2. 模拟土-结构相互作用

```
墙体向土侧移动:
位移 δ → 土弹簧拉伸 → 反力 F = k × δ
→ 模拟土体被压缩产生的反力
```

### 3. 施工过程模拟

```
开挖: 钝化土弹簧 (isAlive = false)
→ 模拟土体被挖走,失去约束

回筑: 激活土弹簧 (isAlive = true)
→ 模拟土体回填,恢复约束
```

## 🔬 技术细节

### 1. 为什么用连杆单元?

```
优点:
✅ 只承受轴向力 (符合土弹簧特性)
✅ 刚度矩阵简单 (计算效率高)
✅ 可以施加初应变 (施加土压力)
✅ 可以激活/钝化 (模拟施工)

缺点:
❌ 不能承受弯矩 (但土弹簧不需要)
```

### 2. 初应变的作用

```
无初应变:
土压力 → 围护墙位移 → 土弹簧反力 = k × δ
→ 初始位移较大 ❌

有初应变:
土弹簧主动产生反力 ≈ 土压力
→ 初始位移很小 ✅
```

### 3. 刚度放大技巧

```
为什么放大1e20倍?
→ 模拟刚性约束
→ 求解得到的位移 ≈ 土压力 / (k × 1e20) ≈ 0
→ 反力 ≈ 土压力
→ 初应变 = 反力 / (E × A)
```

## 📐 计算示例

### 示例: 计算-5m处的土弹簧刚度

**已知条件**:
- 土层: 可塑粘土
- m = 8 MN/m⁴ = 8000 kN/m⁴
- 节点间距: a = 0.2m
- 宽度: b = 1.0m
- 深度: z = 5m

**计算**:
```
ks = a × b × m × z
   = 0.2 × 1.0 × 8000 × 5
   = 8000 kN/m
```

**物理意义**:
- 当围护墙向土侧移动1mm时
- 土弹簧产生反力 = 8000 × 0.001 = 8 kN

## 🎓 理论基础

### Winkler地基模型

土弹簧模型基于**Winkler地基模型**:

```
假定:
1. 地基由一系列独立的弹簧组成
2. 每个弹簧只与其上方的荷载有关
3. 弹簧之间无相互作用

优点:
✅ 概念简单
✅ 计算方便
✅ 工程精度足够

局限:
❌ 忽略土体的连续性
❌ 忽略土体的剪切变形
```

### m法的理论依据

m法来源于**弹性半空间理论**的简化:

```
理论推导:
土的水平抗力系数 k(z) 与深度 z 成正比
→ k(z) = m × z

工程验证:
大量工程实践表明,m法结果与实测值吻合较好
```

## 💡 设计思想

### 为什么这样设计?

1. **物理意义清晰**:
   - 土弹簧 = 土体约束
   - 刚度 = 土的抗力能力
   - 初应变 = 初始土压力

2. **计算效率高**:
   - 连杆单元简单
   - 刚度矩阵稀疏
   - 求解速度快

3. **施工模拟方便**:
   - 激活/钝化机制
   - 刚度动态更新
   - 初应变灵活调整

```

   → 初始位移很小
   → 结果合理
```

## 📚 总结

### 核心要点

1. **模型类型**: m法土弹簧 (Winkler地基模型)
2. **单元类型**: 连杆单元 (Link Element)
3. **刚度公式**: ks = a × b × m × z
4. **关键参数**: m (水平抗力比例系数)
5. **特殊机制**: 初应变 + 激活/钝化

### 物理本质

土弹簧模拟的是**土体对围护墙的弹性约束**,通过简单的线性弹簧模型,实现了对复杂土-结构相互作用的合理模拟!
