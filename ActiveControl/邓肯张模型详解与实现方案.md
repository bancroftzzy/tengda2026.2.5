# 邓肯-张模型详解与实现方案

## 📋 邓肯-张模型概述

### 历史背景

**Duncan-Chang模型** (邓肯-张模型) 由Duncan和Chang于1970年提出,是土力学中最经典的非线性弹性本构模型之一。

### 基本思想

将土体的应力-应变关系用**双曲线**来拟合:

```
σ₁ - σ₃ = ε / (a + b·ε)

其中:
- σ₁: 大主应力
- σ₃: 小主应力 (围压)
- ε: 轴向应变
- a, b: 双曲线参数
```

## 📐 数学模型

### 1. 应力-应变关系

#### 双曲线方程

```
σ₁ - σ₃ = ε / (a + b·ε)

变形为:
ε / (σ₁ - σ₃) = a + b·ε

这是一条直线!
通过三轴试验数据拟合得到a和b
```

#### 图示

```
σ₁-σ₃ ↑
      │        ___________  渐近线: (σ₁-σ₃)ult = 1/b
      │      /
      │     /
      │    /  双曲线
      │   /
      │  /
      └────────────────→ ε
```

### 2. 切线模量

#### 定义

```
Et = dσ / dε = 切线模量 (随应力变化)

对双曲线求导:
Et = 1 / (a + b·ε)²
```

#### 用应力表示

```
Et = Ei × [1 - Rf × (σ₁-σ₃)/(σ₁-σ₃)f]²

其中:
- Ei: 初始切线模量
- Rf: 破坏比 (通常0.7~0.9)
- (σ₁-σ₃)f: 破坏时的偏应力
```

### 3. 初始切线模量

#### 公式

```
Ei = K × Pa × (σ₃/Pa)ⁿ

其中:
- K: 模量系数 (无量纲)
- Pa: 大气压力 (≈100 kPa)
- σ₃: 围压
- n: 模量指数 (通常0.3~0.7)
```

#### 物理意义

- **K**: 反映土的刚度水平
- **n**: 反映刚度随围压的变化率
- **σ₃越大**: 土越"硬" (刚度越大)

### 4. 破坏偏应力

#### 莫尔-库仑准则

```
(σ₁-σ₃)f = 2c·cosφ + 2σ₃·sinφ
           ─────────────────────
                1 - sinφ

其中:
- c: 粘聚力
- φ: 内摩擦角
- σ₃: 围压
```

### 5. 体积模量

#### 切线体积模量

```
Bt = Kb × Pa × (σ₃/Pa)ᵐ

其中:
- Kb: 体积模量系数
- m: 体积模量指数
```

### 6. 泊松比

#### 变化规律

```
ν = G - F × log(σ₃/Pa)

其中:
- G, F: 拟合参数
- 通常: ν = 0.3 ~ 0.45
```

## 🔄 应用于土弹簧

### 1. 基本思路

将邓肯-张模型应用于土弹簧的水平方向:

```
原来 (线性):
F = k × δ
k = 常数

改为 (非线性):
F = f(δ)
k = k(δ) = dF/dδ (切线刚度)
```

### 2. 水平方向的应力-应变

#### 应力状态

```
围护墙后土体:
- 水平应力: σh
- 竖向应力: σv = γ × z
- 水平应变: εh = δ / L

假设:
σ₁ = σv (竖向)
σ₃ = σh (水平)
```

#### 切线模量

```
Eh = K × Pa × (σh/Pa)ⁿ × [1 - Rf × (σv-σh)/(σv-σh)f]²

土弹簧刚度:
k(δ) = Eh × A / L
```

### 3. 迭代求解

由于刚度k依赖于应力σ,而应力又依赖于位移δ,需要**迭代求解**:

```
迭代步骤:
1. 假设初始刚度 k₀
2. 求解位移 δ
3. 根据δ计算应变 ε = δ/L
4. 根据ε计算应力 σ
5. 根据σ更新刚度 k₁
6. 重复2-5直到收敛: |k₁ - k₀| < 容差
```

## 💻 实现方案

### 方案1: 切线刚度法 (推荐)

#### 算法流程

```csharp
// 1. 初始化
k = Ei × A / L  // 初始刚度

// 2. 迭代求解
for (iter = 0; iter < maxIter; iter++)
{
    // 2.1 用当前刚度求解
    FEM.Solve(...) → δ
    
    // 2.2 计算应变
    ε = δ / L
    
    // 2.3 计算应力
    σ = σ_prev + k × ε
    
    // 2.4 更新切线模量
    Et = K × Pa × (σ₃/Pa)^n × [1 - Rf×σ/σf]²
    
    // 2.5 更新刚度
    k_new = Et × A / L
    
    // 2.6 检查收敛
    if (|k_new - k| < tol)
        break
    
    k = k_new
}
```

#### 优点

- ✅ 物理意义清晰
- ✅ 收敛性好
- ✅ 易于实现

#### 缺点

- ❌ 需要迭代 (计算量增加)
- ❌ 可能不收敛 (需要控制)

### 方案2: 割线刚度法

#### 算法流程

```csharp
// 使用割线模量代替切线模量
Es = σ / ε  // 割线模量

k = Es × A / L
```

#### 优点

- ✅ 更稳定
- ✅ 收敛快

#### 缺点

- ❌ 精度略低

### 方案3: 分段线性化

#### 算法流程

```csharp
// 将非线性曲线分段线性化
if (δ < δ₁)
    k = k₁
else if (δ < δ₂)
    k = k₂
else
    k = k₃
```

#### 优点

- ✅ 不需要迭代
- ✅ 计算快

#### 缺点

- ❌ 精度较低
- ❌ 不够光滑

### 步骤2: 创建邓肯-张计算类

```csharp
public class DuncanChangModel
{
    private double K, n, Rf, c, phi, Kb, m, G, F;
    private double Pa = 100.0;  // 大气压 (kPa)
    
    // 计算初始切线模量
    public double GetInitialModulus(double sigma3)
    {
        return K * Pa * Math.Pow(sigma3 / Pa, n);
    }
    
    // 计算破坏偏应力
    public double GetFailureStress(double sigma3)
    {
        double phi_rad = phi * Math.PI / 180;
        double sinPhi = Math.Sin(phi_rad);
        double cosPhi = Math.Cos(phi_rad);
        
        return (2*c*cosPhi + 2*sigma3*sinPhi) / (1 - sinPhi);
    }
    
    // 计算切线模量
    public double GetTangentModulus(double sigma3, double deviatorStress)
    {
        double Ei = GetInitialModulus(sigma3);
        double sigmaf = GetFailureStress(sigma3);
        double ratio = deviatorStress / sigmaf;
        
        if (ratio >= 1.0)
            ratio = 0.99;  // 防止超过破坏
        
        return Ei * Math.Pow(1 - Rf * ratio, 2);
    }
    
    // 计算土弹簧刚度
    public double GetSpringStiffness(double sigma3, double deviatorStress, 
                                     double area, double length)
    {
        double Et = GetTangentModulus(sigma3, deviatorStress);
        return Et * area / length;
    }
}
```

### 步骤3: 修改FEM求解器

```csharp
public static void SolveNonlinear(...)
{
    int maxIter = 50;
    double tol = 1e-6;
    
    // 初始化刚度
    UpdateSpringStiffness(Elements, initialStress: true);
    
    for (int iter = 0; iter < maxIter; iter++)
    {
        // 求解
        Solve(Elements, ref Nodes, Fs, ConstrainedDOFIndex, 
              out Disp, out RForce);
        
        // 更新土弹簧刚度
        double maxChange = UpdateSpringStiffness(Elements, 
                                                 initialStress: false);
        
        // 检查收敛
        if (maxChange < tol)
        {
            Console.WriteLine($"收敛于第{iter+1}次迭代");
            break;
        }
    }
}

private static double UpdateSpringStiffness(List<Element> Elements, 
                                           bool initialStress)
{
    double maxChange = 0;
    
    foreach (var elem in Elements)
    {
        if (elem.ElementType == "Link" && elem.IsSoilSpring)
        {
            // 计算当前应力
            double sigma3 = CalculateConfiningStress(elem);
            double deviatorStress = CalculateDeviatorStress(elem);
            
            // 计算新刚度
            double k_old = elem.RealConstant.Area;
            double k_new = duncanChang.GetSpringStiffness(
                sigma3, deviatorStress, area, length);
            
            // 更新刚度
            elem.RealConstant.Area = k_new;
            
            // 记录最大变化
            double change = Math.Abs(k_new - k_old) / k_old;
            if (change > maxChange)
                maxChange = change;
        }
    }
    
    return maxChange;
}
```

## 📊 对计算结果的影响

### 1. 位移变化

#### 线性模型 vs 邓肯-张模型

```
线性模型:
- 刚度恒定
- 位移与荷载成正比
- 可能低估大变形

邓肯-张模型:
- 刚度随应力降低
- 位移增长更快
- 更接近实际
```

#### 预期影响

```
小变形 (δ < 10mm):
差异 < 10%

中等变形 (10mm < δ < 30mm):
差异 10%~30%
邓肯-张预测位移更大

大变形 (δ > 30mm):
差异 > 30%
线性模型可能严重低估
```

### 2. 内力变化

#### 围护墙弯矩

```
线性模型:
- 土压力分布固定
- 弯矩较大

邓肯-张模型:
- 土压力随变形调整
- 弯矩可能减小 (土体软化)
```

#### 支撑轴力

```
线性模型:
- 支撑力较大

邓肯-张模型:
- 支撑力可能减小
- 更多变形由土体承担
```

### 3. 施工过程影响

#### 开挖过程

```
线性模型:
每次开挖 → 位移增量固定

邓肯-张模型:
每次开挖 → 位移增量递增
(因为刚度逐渐降低)
```

#### 支撑安装

```
线性模型:
支撑效果固定

邓肯-张模型:
支撑效果可能更显著
(因为土体已经软化)
```
