# 工程文件与多方法结果

## 菜单

顶部依次为“工程菜单、数据录入、数据导出、查看结果”。

- 新建工程：清空输入、计算结果和显示，其他参数回到空白工程默认值；不会删除已保存文件。有未保存内容时提示保存。
- 打开工程：读取 `.acproj` 文件，恢复输入和各方法结果。完整解析、验证后才替换当前工程。
- 保存工程：每次弹出文件窗口，默认当前路径和文件名。选择相同路径就是更新，选择其他路径就是另存一份。
- 查看结果：直接计算、全局粒子群、分区粒子群、零位移法、手动赋值，各自独立保存最近一次计算的数据。

软件启动时恢复最近通过菜单保存或打开的工程。没有最近工程时进入空白工程，不再自动加载程序目录下的调试用 ImportData。原来的单项 TXT 读取、写入入口仍保留；第一次使用可按原流程录入后保存工程。

## 文件内容

`.acproj` 是带格式标识和版本号的 JSON 工程文件，当前版本为1。包含：

- 当前土层、支撑、施工阶段、局部荷载和其他参数；空局部荷载列表也会保存。
- 地下水开关、水位、非线性土弹簧开关、土层水土模式及邓肯—张参数。
- 每种方法计算时的独立输入副本、时间、状态、已完成阶段数。
- 每个已归档阶段的节点坐标和位移、单元生死及初应变、单元实际内力、外荷载和约束反力。
- 各支撑的累计千斤顶行程、接触点位移、弹性压缩量。
- 包含原程序逐根调节过程的包络，以及该方法在输出窗口中的日志、调节表格。
- 手动赋值各已计算阶段的目标轴力输入。

数值直接按内部单位、往返精度保存，不采用 TXT 导出的显示小数位，避免反复保存产生舍入和单位换算误差。

## 查看和重新计算

选择结果方法后，日志、阶段选择、图形和数据导出同时对应该方法。查看历史结果不修改当前输入或用于继续计算的工作模型，也不会重新求解有限元。

单阶段位移图沿用绿色曲线、灰色零位移虚线和黑色支撑实线。支撑线连接到该阶段实际的墙体接触点位置；位移图横轴保持左右对称。包络使用紫色最大值和红色最小值。

打开计算控制窗口不再自动初始化。点击开始计算时，首次计算、切换计算方法、输入已修改、上次已全部完成或上次被终止/异常，会从第一阶段重新初始化。同一种方法的逐工况计算可以继续下一个阶段。计算中不允许切换工程、编辑输入或切换结果，避免共享模型被修改。

没有数据的方法会提示“没有可查看计算结果”；部分计算只列出已完整保存的阶段，不把其余全零数组当成结果。优化调节失败会明确标记失败，保存该阶段未执行目标调节的结构状态。

修改输入后，旧结果仍可查看，但显示“对应旧输入”。旧结果所用的输入副本随结果保留。重新计算一种方法只替换该方法的结果，其他方法仍然保留。

工程恢复支持查看、导出，以及基于当前输入重新计算；不支持恢复中断时的粒子位置、线程或千斤顶小步执行现场。终止计算只保留已完整归档阶段，重新启动该次计算会从第一阶段开始。

## 实现位置

- `Classes/ProjectData.cs`：输入和结果快照、版本验证、JSON读写及原子保存。
- `Forms/Form_Main.Project.cs`：工程菜单、打开/保存/清空、最近工程恢复、结果归档和方法选择。
- `Forms/Form_Main.Results.cs`：已保存结果的绘图和导出。
- `Forms/Form_Calculate.Project.cs`：计算启动和阶段归档，区分完成、失败、终止状态。
- `Form_Main.cs`、`Form_Calculate.cs`：原按钮接入上述功能。

本次未修改 `FEM.cs`、土弹簧本构或粒子群数学搜索公式。逐根调节过程中禁止受拉的方案尚未实施。

## 验证

`tests/ProjectPersistenceSmokeTests.cs` 是独立的 STA 集成测试。对小型有限元算例运行五种方法，验证各自保存、重新打开、切换图形与导出；比较直接计算与原 Construction/Solve 工作流的阶段位移；还检查空荷载、200mm上限、旧输入标记、部分阶段、失败阶段、无结果方法和损坏文件保护。

测试不操作用户正在运行的程序，不写最近工程配置，不覆盖原输入 TXT。可用 Visual Studio 的 Roslyn `csc.exe` 编译测试，引用生成的 `ActiveControl.exe`、`MathNet.Numerics.dll`、Windows Forms、Drawing、DataVisualization、Runtime.Serialization，运行时传入测试输出目录。
